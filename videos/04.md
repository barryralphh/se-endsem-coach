# Unit 4: Software Testing

## 10 Golden Points
1. Error is human galti, fault is the bug in code, failure is the wrong behaviour the user sees: Error to Fault to Failure
2. Verification asks are we building the product right, it is static, uses reviews and inspections, no code runs
3. Validation asks are we building the right product, it is dynamic, code is executed with test cases
4. Levels of testing: unit, integration, system, acceptance. Integration can be top down, bottom up, big bang or sandwich
5. White box testing looks inside the code, black box testing checks only inputs and outputs
6. Cyclomatic complexity V of G equals E minus N plus 2, or P plus 1, or number of regions
7. V of G is the number of independent paths, so you need at least that many test cases
8. Boundary value analysis: min minus, min, min plus, nominal, max minus, max, max plus. Normal BVA gives 4n plus 1 cases, robust gives 6n plus 1
9. Equivalence class testing: split input into valid and invalid classes and test one value from each class
10. Decision table: conditions on top, actions below, every column is a rule and one test case. TDD cycle is Red, Green, Refactor

## Worked calculations

### Scene 4: Coverage % = executed / total x 100
    ## Statement coverage
    ? 10 statements, 8 executed
    Coverage = 8 / 10 x 100
    ! Statement coverage = 80 percent
    ## Branch coverage
    ? 6 branches, 4 taken
    Coverage = 4 / 6 x 100
    ! Branch coverage = 66.7 percent
    ~ Branch coverage is stronger than statement

### Scene 5: Flow graph: Node = statement, Edge = raasta, Predicate = decision
    ## Cyclomatic complexity V(G)
    Formula 1: V(G) = E - N + 2
    Nodes N = 10 (with end node)
    Edges E = 12
    V(G) = 12 - 10 + 2 = 4
    Formula 2: V(G) = P + 1
    Predicate nodes P = 3
    V(G) = 3 + 1 = 4
    Formula 3: V(G) = regions = 4
    ! V(G) = 4 -> 4 independent paths
    ## Independent paths
    P1: 1-2-3-end
    P2: 1-2-4-5-6-end
    P3: 1-2-4-5-7-8-end
    P4: 1-2-4-5-7-9-end

### Scene 6: V(G) paths = minimum test cases. Mini numericals bhi kar lo!
    ## Mini numerical 1
    ? E = 17, N = 13
    V(G) = E - N + 2
    V(G) = 17 - 13 + 2
    ! V(G) = 6
    ## Mini numerical 2
    ? Code has if, while, if
    P = 3
    V(G) = 3 + 1
    ! V(G) = 4
    ~ Loop condition also counts as predicate

### Scene 7: 3 decisions -> V(G) = 4 -> test cases likho, coupon + new = refuse!
    ## White box test cases
    V(G) = 3 decisions + 1 = 4
    (strict, 5 conditions: 5 + 1 = 6)
    TC1: new, no coupon -> 15%
    TC2: existing + loyalty -> 10%
    TC3: existing, coupon, no loyalty -> 20%
    TC4: existing + loyalty + coupon -> 30%
    TC5: new + coupon -> 15% (coupon refused)
    TC6: existing, no loyalty, no coupon -> 0%
    ! 4 paths minimum, 6 cases cover all branches
    ~ Discounts are added: 10 + 20 = 30

### Scene 8: Normal BVA = 4n+1. Robust BVA = 6n+1. n = number of inputs
    ## Normal BVA, 13 cases (a, b, c)
    vary a: (1,50,50) Real | (2,50,50) Real
    (99,50,50) Imag | (100,50,50) Imag
    vary b: (50,1,50) Imag | (50,2,50) Imag
    (50,99,50) Imag | (50,100,50) Equal
    vary c: (50,50,1) Real | (50,50,2) Real
    (50,50,99) Imag | (50,50,100) Imag
    nominal: (50,50,50) Imag
    ! 4 x 3 + 1 = 13 cases
    ## Robust adds 6 more
    a=0, a=101, b=0, b=101, c=0, c=101
    ~ Out of range -> Invalid input (a=0 may be Not quadratic)
    ? Single input age 18 to 60
    ! Test 17, 18, 19, 39, 59, 60, 61

### Scene 9: Equivalence = ek group se ek test. Decision table = har rule ek test
    ## Equivalence classes
    ? Age field valid 18 to 60
    Class 1 invalid: age < 18 -> test 10
    Class 2 valid: 18 to 60 -> test 35
    Class 3 invalid: age > 60 -> test 70
    ! 3 classes = 3 test cases
    ~ BVA then adds 17, 18, 60, 61

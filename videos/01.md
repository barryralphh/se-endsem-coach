# Unit 1: Introduction, SDLC, Agile

## 10 Golden Points
1. Software engineering is a systematic, disciplined and quantifiable approach to develop, operate and maintain software
2. Software is developed not manufactured, it does not wear out but it deteriorates when changes keep coming
3. Software crisis means projects crossing cost, crossing time and giving poor quality, because of no process and changing requirements
4. SDLC phases: Requirements, Design, Coding, Testing, Maintenance. Each phase gives an output: SRS, design document, code, test report, updated software
5. Structured approach thinks in functions and uses DFD, OOAD thinks in objects and uses UML
6. OOAD gives better reuse and easier change because data and functions stay together inside the object
7. Agile is CRISP: Customer involvement, Requirement change welcome, Iterations small, Size of documents light, Planning adaptive
8. Scrum has 3 roles: Product Owner, Scrum Master, Team, and sprints of 2 to 4 weeks with daily scrum
9. XP practices: pair programming, TDD, refactoring, continuous integration, small releases, simple design
10. FDD has 5 steps, starting with develop an overall domain object model, then build feature list, plan, design and build by feature

## Worked calculations

### Scene 8: FDD: Overall model -> Feature list -> Plan -> Design -> Build by feature
    ## Role of domain object modelling
    Experts + chief architect draw classes
    Shows real objects and their links
    Gives one shared language to all
    ## Contribution to success
    Feature list comes from the model
    Less rework, class owners are clear
    Progress tracked feature by feature
    ## Challenges
    Needs good domain experts, time upfront
    Wrong model spreads to all features
    Hard to change if domain changes

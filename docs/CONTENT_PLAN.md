## UNIT 4: Testing (BUILD FIRST)

Verification vs validation table (PYQ 4a): verification = static, reviews/walkthrough/inspection, no execution, 'building the product right'; validation = dynamic, executes code, 'building the right product'. Test-case design methods (black/white box) belong mainly to validation; both sit inside one overall test strategy.

Independent paths: 1-2-3-10; 1-2-4-5-6-10; 1-2-4-5-7-8-10; 1-2-4-5-7-9-10. Test cases (a,b,c): (0,5,3) Not quadratic; (1,2,1) Equal; (1,5,2) Real; (5,1,2) Imaginary. Mini numericals: E=17,N=13 => 6; P=5 => 6.
5. **PYQ 4c discount scenario** (white box): decisions D1 new customer (+15%), D2 existing AND loyalty card (+10%), D3 coupon AND NOT new customer (+20%), discounts add. ## UNIT 5: Management, quality, metrics (BUILD SECOND)
1. Unit map.
2. **Size and quality metrics**. Pressman example: 12,100 LOC, 24 person-months, cost 168,000, 365 doc pages, 134 errors before release, 29 defects after. Productivity = 12.1/24 = 0.504 KLOC/PM (504 LOC/PM); errors/KLOC = 11.07; defects/KLOC = 2.40; cost/LOC = 13.88; pages/KLOC = 30.2; DRE = E/(E+D) = 134/163 = 82.2%. **Failure percentage** = failures/runs x 100 (200 runs, 6 fail = 3%, reliability 97%). MTBF = MTTF + MTTR; availability = MTTF/(MTTF+MTTR) (200, 20 => 220 h, 90.9%).
3. **Function Points**: EI(3/4/6) EO(4/5/7) EQ(3/4/6) ILF(7/10/15) EIF(5/7/10). Example, all average: EI 50x4=200, EO 40x5=200, EQ 35x4=140, ILF 6x10=60, EIF 4x7=28 => UFP=628. 14 GSC sum=46 => VAF = 0.65+0.01x46 = 1.11 => FP = 697.08 ~ 697. Effort = FP / productivity.
4. **COCOMO** Basic: E = a (KLOC)^b, T = c E^d, staff = E/T; organic 2.4/1.05/2.5/0.38, semi 3.0/1.12/2.5/0.35, embedded 3.6/1.20/2.5/0.32. Example organic 32 KLOC: 32^1.05=38.05, E=91.3 PM, T=13.9 months, staff 6.6. Intermediate: E = a (KLOC)^b x EAF (a: 3.2/3.0/2.8). **PYQ 3b**: EAF = 0.75x1.10x1.20x0.90 = 0.891; 50^1.2 = 109.34; nominal = 2.8x109.34 = 306.14; **Effort = 306.14 x 0.891 = 272.8 person-months**; (if embedded c,d used) T = 2.5 x 272.8^0.32 = 15.0 months, staff = 18.1.
5. Scheduling: Gantt, CPM (forward pass ES/EF, backward LS/LF, slack = LS-ES, critical path = zero slack), PERT te=(O+4M+P)/6, SD=(P-O)/6. Example: A3, B4(A), C2(A), D5(B), E3(C), F2(D,E): A-B-D-F = 14 critical; C,E slack 4. Effect on integration testing (PYQ 4b): late modules shrink test time, module finish order forces top-down/bottom-up choice, stubs/drivers, critical path slip = rushed integration = escaped defects. Staffing: Brooks law; staff = effort/time.
6. SCM (baseline, version control, change control, audit, status report), QA vs QC, ISO 9001, project monitoring with earned value: PV=100, EV=80, AC=90 => SPI 0.80 (behind), CPI 0.89 (over cost).
7. **Risk**: known (found by evaluating plan/environment), predictable (extrapolated from past projects, e.g. turnover), unpredictable. Risk components (performance, cost, support, schedule) vs risk drivers (factors that push each component; impact negligible/marginal/critical/catastrophic). RE = P x C (0.4 x 50,000 = 20,000). RMMM. Risk in agile: short iterations, backlog reprioritising, daily scrum.
8. Quality dilemma (PYQ 5b: awful quality = nobody buys, perfect quality = too late and too costly, aim for good enough), quality vs security (security is one attribute of quality: confidentiality, integrity, availability).
9. McCall (PYQ 5c): 11 factors in 3 groups. Operation: correctness, reliability, efficiency, integrity, usability. Revision: maintainability, flexibility, testability. Transition: portability, reusability, interoperability. Factor -> criteria -> metrics; score example 0.4x8+0.3x6+0.3x7=7.1.
10. CMM levels: 1 Initial, 2 Repeatable/Managed, 3 Defined, 4 Quantitatively Managed, 5 Optimizing. Maintenance types: corrective, adaptive, perfective, preventive. Trends.
